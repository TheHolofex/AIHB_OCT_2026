# AI Harness Bootcamp

You can use an AI model to help with a task while keeping the evidence, permissions, and final decision in your hands. These ten fictional desk assignments take you from a bounded first draft to a package another person can operate without your chat history.

You’ll use Oh My Pi 18.3.5 with `openrouter/anthropic/claude-sonnet-4.6` and one OpenRouter API key. Git, Python 3.12 or newer, a browser, and an ordinary text editor are the other required tools. Start with setup before making a paid request.

Each assignment supplies its own case files. Earlier skills remain prerequisites, but you do not need a previous assignment’s output to begin the next one. Keep your work outside the repository so that your original attempts and the supplied inputs remain separate.

## Keep the result bounded

A `PASS` belongs to the check that produced it. It does not authorize a real release, dispatch, clinical decision, or public disclosure. When a prerequisite is missing or a claim lacks support, preserve the result and record `HOLD`.

The practice targets are a first checked result within 60 minutes and up to two hours of independent work per assignment. Those are planning targets, not measured completion times. Optional stretch work asks for stronger judgments and evidence; it is separate from the required path.

A technical replay does not show whether another person can use the package. Observe their actions and questions separately from file checks and model responses.

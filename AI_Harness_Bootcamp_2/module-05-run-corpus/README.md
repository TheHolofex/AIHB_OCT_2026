# Module 5 · Improve from observed failures

Plan for one three-hour session. You will freeze a sample of sixteen runs before you open outcomes, write first-failure notes, reconcile counts to sixteen, infer two literal strings, configure them in the supplied predicate, and run known-bad, known-good, and missing input.

The runs are class review notes about oxygen-cylinder movements from East Yard to Clinic O-2. They are not a live operations log.

## The supplied check

The supplied predicate matches two configured literal strings as case-sensitive substrings inside one run file. It exits 1 when both are present and 0 when at least one is absent. A missing run file prints `HOLD: missing input`. A malformed configuration prints `HOLD: malformed config`. You write the two strings. You do not write a second checker.

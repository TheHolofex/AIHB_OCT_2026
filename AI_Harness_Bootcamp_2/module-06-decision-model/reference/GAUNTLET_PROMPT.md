Review criteria:
- Native two-line start/resume cards only; no long discovery, path-variable, key-export, or one-shot launcher command blocks in learner prose.
- Four patterns presented in exact TypeSafe source order with cumulative capability.
- Each pattern shows: purpose, one primary ~60-word OMP prompt, actual expected native visual description, meaningful learner change prompt (configuration change that is executed or replayed), source/behavior check, concise Expected/Stop/Recovery.
- Model identity stated once as a small fixed fact.
- One shared transfer/authority paragraph that correctly separates message text from source records and states that no route, score, or draft authorizes cargo movement.
- Serial arm then fan-out arm on identical 20 practice messages and identical six questions; fan-out change is the meaningful configuration step; ignored answers marked; cold namespaces used; no promised speedup.
- Confidence: replays at 0.4/0.6/0.8 with zero additional Jev; learner chooses gate pair and ceiling; one frozen unseen run of 60; no retuning on unseen labels; code-only rows explicit.
- Scoring: 80 normalized scores; two weight sets compared by replay only (0.5/0.3/0.2 then 0.2/0.6/0.2); learner third set by replay; BG-012/BG-014 contributions inspected; zero new Jev on reweight.
- Intent: 16 requests; Jev classification only; three real handlers (record lookup, deterministic record comparison, human officer queue) where gates and saved choices allow; strict-gate replay labeled preview with no handler execution; main chat calls distinguished from Jev usage; record comparison defined as code selecting applicable records for exact cargo, flight, and snapshot time.
- Final handoff prompt produces four-row pattern comparison (change/effect/limitation/run ID), one concrete per-pattern example, leading unresolved messages with source references and human owners; packet explicitly labeled "review packet — not a manifest or movement order".
- Held-out worked answers and labels absent from all pre-freeze prose, prompts, and early panels.
- Operated case/controls links present; DESK_RULES, PATTERNS, MISSION, scans, flight_acceptances referenced appropriately.
- No making-of, curriculum-design commentary, learner scores, or qualification rubrics in learner-facing pages.
- Voice is guide-beside: purpose before procedure, one idea per sentence, jargon defined at first need, failure normalized, no overclaim.
- Independence: learner prompt produces inspected, executed configuration change; supplied engine owns all executable mechanics.
- HOLD behavior: incomplete, held, or critical-miss results are preserved and reported as valid evidence; no silent retry or erasure.
- Parsimony: short prompts, short launch, no parallel learner Markdown pages.

- An eval cell other than a prepare-issued frozen cell.
- A message's embedded instruction obeyed or never reviewed.
- An authorization request routed to a non-human handler.

- The final packet labeled a manifest, movement order, or clearance.
- Staff tokens, other modules' cases, or worked question sets in learner files.
